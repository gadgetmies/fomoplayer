Findings

1 · A dark-ambient false-positive cluster in every set

40 plays across the four sets come from a handful of dark-ambient and dark-techno labels that no DJ here played. They arrive in bursts (several previews within a minute or two), with tempo factors scattered over the whole ±8 % search range (genuine plays here sit between 0 and +2.5 %), and pass the significance gate (10–16). The passages are not quiet (RMS −8 to −13 dB, the same as the rest of each set), so it is not silence matching silence. A per-preview prior — how often a preview matches across unrelated sets — or a limit on simultaneous new plays could remove them (untested); either is a code change for a new worktree.

2 · Seen but rejected vs never seen

For each miss with a fingerprinted preview the tables show how many 30 s windows had that track as a candidate and its best window score. Skeptical's misses were, all but one, seen (4–8 windows, best score 6–11) and lost in refinement — a threshold question. Sorza's were mostly never seen: the set is mostly Sorza's own edits and flips, so the released preview audio never plays.

3 · Catalogue coverage is the main limit

67 of 143 named tracks across the judged sets have no fingerprinted preview in the version played — unreleased edits, VIPs, bootlegs and older tracks missing from the stores Fomo Player follows; Bandcamp and Spotify entries without fingerprinted previews. Bandcamp previews (full tracks) are still being fingerprinted by the drain.
