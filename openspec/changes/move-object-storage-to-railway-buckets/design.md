## Context

Two kinds of objects live in object storage:

- notification audio samples, uploaded by users through
  `POST /api/me/notifications/audio-samples`, under
  `notification-samples/<userId>/<uuid>.<ext>`;
- waveform PNGs generated by `analyser/waveform.py`, under `<uuid>.png`.

Both were served publicly from the MinIO host, and the absolute URL
(`https://<host>/<bucket>/<key>`) was stored in the database. MinIO had one
bucket per kind (`sample-storage`, `fomo-player-waveforms`). Their keys do not
collide, so the Railway bucket holds both at its root, with the keys unchanged.

## Decisions

### Serve through a redirect, not a proxy

Railway buckets cannot be public. The API answers `GET /api/storage/*key` with
`302 Found` to a presigned URL. The browser then downloads straight from the
bucket, so the service pays no egress and holds no file in memory. `<audio>`,
`<img>` and `urllib`/`requests` all follow the redirect.

The route is unauthenticated, like the public bucket it replaces: waveform
images and sample previews were already readable by anyone who had the URL,
and the keys are random UUIDs. The redirect carries
`Cache-Control: private, max-age=300`, well inside the one-hour presign expiry,
so a browser re-requests the redirect before the signed URL can lapse.

### Store a path, not an absolute URL

The stored URL becomes `/api/storage/<key>`. The front end is served from the
same origin as the API (and proxies `/api` in development), so the path works
as-is in every deployment and does not embed a hostname (repository
configuration policy). The analyser resolves `/api/...` paths against the
origin of `FOMOPLAYER_API_URL`.

### Rewrite existing rows in a migration, matched by bucket path

The migration rewrites a URL only when it has the shape
`http(s)://<any host>/<bucket>/<key>` for the storage buckets:
audio samples by their own `_bucket` and `_object_key` columns, waveforms and
previews by the historical waveform bucket name `fomo-player-waveforms`.
Store-provided URLs (Bandcamp, Beatport, Spotify) never contain those paths and
are untouched. No deployment hostname appears in the migration. The down
migration cannot restore the original host and is a no-op.

### One client, any S3 store

The `minio` package already speaks plain S3. Two optional settings cover
Railway: `AUDIO_SAMPLE_STORAGE_REGION=auto` and
`AUDIO_SAMPLE_STORAGE_URL_STYLE=virtual`. Unset, behaviour matches a local
MinIO. Creating a missing bucket no longer sets a public-read policy.

## Risks

- Objects uploaded to MinIO after the copy and before the switch-over: the copy
  job is re-run right before switching the production variables.
- Pull-request preview environments still run their own MinIO; the new code
  works against it because presigned URLs work there too.
